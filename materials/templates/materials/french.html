Adjectifs — Accord & Position
Accord de l'adjectif Débutant
Règle : L'adjectif s'accorde en genre et en nombre avec le nom.

Masc. sing. : un garçon grand
Fém. sing. : une fille grande
Masc. plur. : des garçons grands
Fém. plur. : des filles grandes
Terminaison masc.FémininExemple
-e (déjà fém.)-erouge → rouge
-eux-euseheureux → heureuse
-if-iveactif → active
-ier-ièreentier → entière
-el/-eil/-ildouble + enaturel → naturelle
Irrégulier—beau→belle, vieux→vieille, nouveau→nouvelle
Position BANGS Intermédiaire
BANGS = adjectifs qui se placent AVANT le nom :
Beauty — beau, joli
Age — jeune, vieux, nouveau
Number — premier, deuxième, dernier
Goodness — bon, mauvais, gentil
Size — grand, petit, gros, long

✓ une belle maison | ✓ un petit chat
Tous les autres adjectifs : APRÈS le nom.
✓ une voiture rouge | ✓ un homme intelligent

Passé Composé
Formation Intermédiaire
Passé composé = auxiliaire (avoir ou être) au présent + participe passé

-ER → -é : parler → parlé
-IR → -i : finir → fini
-RE → -u : vendre → vendu
Irréguliers : être→été avoir→eu faire→fait venir→venu prendre→pris mettre→mis
Auxiliaire AVOIR vs ÊTRE — La Maison d'Être Intermédiaire
→ ÊTRE : verbes de mouvement/état + tous les verbes pronominaux
aller, venir, partir, arriver, entrer, sortir, monter, descendre,
naître, mourir, rester, tomber, retourner, passer + pronominaux (se laver…)

→ AVOIR : tous les autres verbes.

Accord avec ÊTRE : le participe s'accorde avec le sujet
✓ Elle est partie. ✓ Ils sont arrivés. ✓ Elles sont tombées.

Accord avec AVOIR : s'accorde avec le COD placé avant le verbe
✓ Les fleurs qu'il a cueillies. ✓ Je les ai vues.
Imparfait
Formation Intermédiaire
Base : radical de la 1ʳᵉ personne du pluriel (nous) au présent
Terminaisons : -ais / -ais / -ait / -ions / -iez / -aient

parler : nous parlons → parl- → je parlais, tu parlais, il parlait…
Exception : être → ét- (j'étais, tu étais, il était…)
UsageExemple
Habitude passéeQuand j'étais enfant, je jouais au foot.
Description (passé)Il faisait beau ce jour-là.
Action en cours (interrompue)Je dormais quand le téléphone a sonné.
Politesse (imparfait de politesse)Je voulais vous demander un service.
Futur
Futur proche vs Futur simple Intermédiaire
Futur proche : aller (présent) + infinitif ← action imminente
Je vais manger. Tu vas partir. Il va pleuvoir.

Futur simple : infinitif + terminaisons ← action future générale
Terminaisons : -ai / -as / -a / -ons / -ez / -ont
parler → je parlerai, tu parleras, il parlera…
VerbeRadical irrégulierExemple

pouvoirpourr-ils pourront
vouloirvoudr-je voudrai

Comparatif & Superlatif
Comparatif Intermédiaire
Supériorité : plus + adjectif/adverbe + que
Égalité : aussi + adjectif/adverbe + que
Infériorité : moins + adjectif/adverbe + que

✓ Marie est plus grande que Paul.
✓ Il court aussi vite qu'elle.
✓ Ce film est moins intéressant que l'autre.

Irréguliers : bon → meilleur | bien → mieux | mauvais → pire
Superlatif Intermédiaire
Superlatif relatif : le/la/les + plus/moins + adjectif (+ de)
✓ C'est la plus belle ville de France.
✓ Il est le moins rapide de l'équipe.

Superlatif absolu : très / extrêmement / absolument + adjectif
✓ Ce gâteau est absolument délicieux.
Subjonctif
Formation du subjonctif présent Avancé
Base : radical de la 3ᵉ personne du pluriel (ils) au présent
Terminaisons : -e / -es / -e / -ions / -iez / -ent

parler : ils parlent → parl- → que je parle, que tu parles…
finir : ils finissent → finiss- → que je finisse…

Irréguliers : être → soit | avoir → ait | aller → aille | faire → fasse | pouvoir → puisse
Déclencheurs du subjonctifExemple
Volonté : vouloir, désirer, souhaiter queJe veux qu'il vienne.
Nécessité : il faut que, il est nécessaire queIl faut que tu partes.
Doute/incertitude : douter que, ne pas croire queJe doute qu'il ait raison.
Émotion : être content/triste/surpris queJe suis content qu'elle soit là.
Conjonctions : bien que, pour que, avant que, à moins queBien qu'il fasse froid, je sors.
Conditionnel
Conditionnel présent & passé Avancé
Conditionnel présent : radical du futur + terminaisons de l'imparfait
Terminaisons : -ais / -ais / -ait / -ions / -iez / -aient
parler → je parlerais, tu parlerais, il parlerait…

Conditionnel passé : auxiliaire au conditionnel + participe passé
J'aurais parlé. Elle serait partie.
Hypothèse (Si…)StructureExemple
Réelle (futur)Si + présent, futur simpleSi je mange, je grossirai.
Irréelle (présent)Si + imparfait, cond. présentSi j'avais de l'argent, j'achèterais.
Irréelle (passé)Si + plus-que-parfait, cond. passéSi j'avais étudié, j'aurais réussi.
Plus-que-parfait
Formation & Usage Avancé
Formation : auxiliaire (avoir/être) à l'imparfait + participe passé

J'avais mangé. Il était parti. Elles s'étaient levées.

Usage : action passée antérieure à une autre action passée
✓ Quand il est arrivé, j'avais déjà fini.
✓ Elle a dit qu'elle avait vu ce film. (discours indirect)
Voix Passive
Formation & Transformation Avancé
Voix active : Sujet + verbe + COD
Voix passive : COD (devenu sujet) + être (au même temps) + participe passé + par + agent

✓ Actif : Le chat mange la souris.
✓ Passif : La souris est mangée par le chat.

✓ Actif : La police a arrêté le voleur.
✓ Passif : Le voleur a été arrêté par la police.

⚠️ Le participe passé s'accorde avec le nouveau sujet.
Discours Indirect
Concordance des temps Avancé
Discours direct→Discours indirect (passé)
Présent→Imparfait
Passé composé→Plus-que-parfait
Futur simple→Conditionnel présent
Futur antérieur→Conditionnel passé
Impératif→de + infinitif
Direct : Il dit : « Je suis fatigué. »
Indirect : Il dit qu'il était fatigué.

Direct : Elle a dit : « Je viendrai demain. »
Indirect : Elle a dit qu'elle viendrait le lendemain.

Changements de mots : aujourd'hui→ce jour-là | demain→le lendemain | hier→la veille | ici→là

Stylistique & Figures de Style
Figures de style essentielles Avancé
FigureDéfinitionExemple
ComparaisonRapproche deux éléments avec un outil comparatif (comme, tel, ainsi que…)Il est courageux comme un lion.
MétaphoreIdentification directe sans outil comparatifC'est un lion dans l'arène.
PersonnificationAttribue des caractéristiques humaines à un non-humainLe vent gémissait dans les arbres.
HyperboleExagération pour renforcer une idéeJe meurs de faim !
LitoteDire moins pour suggérer plusCe n'est pas mal. (= C'est très bien.)
EuphémismeAtténuer une réalité dureIl nous a quittés. (= Il est mort.)
AntithèseOpposer deux idées contrastéesL'homme est mortel, l'art est éternel.
AllitérationRépétition d'un son consonantiquePour qui sont ces serpents qui sifflent sur vos têtes ?
AnaphoreRépétition d'un mot en début de phraseJ'ai rêvé… J'ai lutté… J'ai vaincu.
ChiasmeStructure croisée ABBAIl faut manger pour vivre, non vivre pour manger.
OxymoreAssociation de termes contradictoiresUn silence éloquent. / Cette obscure clarté.
IronieDire le contraire de ce qu'on penseQuelle surprise ! (en voyant quelque chose de prévisible)
