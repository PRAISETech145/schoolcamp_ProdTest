Statistics & Probability
Measures of Central Tendency Basic
Mean: x̄ = Σx / n
Weighted Mean: x̄ = Σ(f·x) / Σf

Mode: most frequent value

Sequences & Series
Arithmetic Progression (AP) Basic
nth term: Tₙ = a + (n−1)d
Sum: Sₙ = n/2 × [2a + (n−1)d] = n/2 × (a + l)

a = first term, d = common difference, l = last term.

Geometric Progression (GP) Basic
nth term: Tₙ = a·rⁿ⁻¹
Sum (r≠1): Sₙ = a(rⁿ−1) / (r−1)
Sum to ∞ (|r|<1): S∞ = a / (1−r)

General term: Tr+1 = C(n,r) · aⁿ⁻ʳ · bʳ
