Stoichiometry
Mole Concept Basic
Moles: n = m / M [mol]
Particles: N = n x Na (Na = 6.022x10^23)
Gas (STP): V = n x 22.4 L
Gas (RTP): V = n x 24.0 L
Concentration: c = n / V [mol/L]
Dilution: c1V1 = c2V2

m = mass (g), M = molar mass (g/mol), V = volume (L).

Empirical & Molecular Formula Intermediate
Step 1: % --> mass (assume 100 g sample)
Step 2: moles = mass / molar mass for each element
Step 3: divide all by smallest mole value (whole ratios)
Molecular formula: (empirical) x n
n = Molecular mass / Empirical formula mass
Yield & Purity Intermediate
% yield: (actual / theoretical) x 100%
% purity: (pure mass / total mass) x 100%
% composition: (element mass / molar mass) x 100%

Thermochemistry
Enthalpy & Heat Intermediate
Heat: q = mcDT [J]
Enthalpy: DH = SH(products) - SH(reactants)
Standard DH: DH_rxn = SDHf(products) - SDHf(reactants)
Bond energy: DH = S(bonds broken) - S(bonds formed)
Hess's Law: DH_total = S(DH_steps)
Gibbs Free Energy Advanced
DG = DH - TDS [J/mol]
Spontaneous if: DG < 0
DG_std = -RT ln(K)
DG = DG_std + RT ln(Q)

T in Kelvin. DS = entropy change (J/mol·K).

Chemical Kinetics
Rate Laws & Arrhenius Advanced
Rate law: rate = k[A]^m [B]^n
Zero order: [A] = [A]0 - kt
First order: ln[A] = ln[A]0 - kt
Second order: 1/[A] = 1/[A]0 + kt
Half-life (1st): t1/2 = 0.693 / k
Arrhenius: k = A * e^(-Ea/RT)
Chemical Equilibrium
Equilibrium Constants Intermediate
For: aA + bB = cC + dD
Kc = [C]^c [D]^d / ([A]^a [B]^b)
Kp = Kc(RT)^Dn (Dn = moles gas products - reactants)
Ksp (solubility): Ksp = [A+]^a [B-]^b

If Q < K forward; Q > K reverse; Q = K equilibrium.

Le Chatelier's Principle Intermediate

Add product← Reverse
Increase pressure→ fewer moles of gas
Increase temperature→ endothermic direction

Acids & Bases
pH, pOH & Constants Basic
pH = -log[H+]
pOH = -log[OH-]
pH + pOH = 14 (at 25°C)
Kw = [H+][OH-] = 1x10^-14 (at 25°C)
pKa = -log(Ka) | pKa + pKb = 14
Henderson-Hasselbalch: pH = pKa + log([A-]/[HA])
Key Acid-Base Equations Basic
HCl --> H+ + Cl- (strong acid)
NaOH --> Na+ + OH- (strong base)
HCl + NaOH --> NaCl + H2O (neutralisation)
H2SO4 + 2NaOH --> Na2SO4 + 2H2O
CaCO3 + 2HCl --> CaCl2 + H2O + CO2 (acid + carbonate)
Zn + H2SO4 --> ZnSO4 + H2 (gas) (acid + metal)
NH3 + H2O = NH4+ + OH- (weak base)
Redox & Electrochemistry
Oxidation States & OIL RIG Basic
OIL RIG: Oxidation Is Loss; Reduction Is Gain (of electrons)
Oxidising agent: gains e- (gets reduced)
Reducing agent: loses e- (gets oxidised)
Rules: pure element=0 | H=+1 | O=-2 | ion sum=charge
Electrochemistry Formulas Advanced
E_cell = E_cathode - E_anode
DG_std = -nFE_std
Faraday's law: m = (M x I x t) / (n x F)
Nernst eq.: E = E_std - (RT/nF) ln(Q)

F = 96485 C/mol, n = moles electrons, I = current (A), t = time (s).

2H2O --> 2H2 + O2 (electrolysis)
MnO4- + 8H+ + 5e- --> Mn2+ + 4H2O (half-reaction, acidic)

Organic Synthetic Routes
Alkanes — Preparation & Reactions Basic
1. Free-radical halogenation (substitution):
CH4 + Cl2 --> CH3Cl + HCl (UV light; initiation/propagation/termination)

2. Catalytic cracking (long → short alkanes + alkenes):
C10H22 --> C4H10 + C3H6 + C3H8 ... (zeolite/Al2O3, 400–500°C)

3. Hydrogenation of alkenes → alkanes:
CH2=CH2 + H2 --> CH3CH3 (Ni catalyst, 150°C)

4. Wurtz reaction (C-C coupling):
2CH3Br + 2Na --> CH3CH3 + 2NaBr (dry ether; doubles carbon chain)

Free-radical mechanism: Initiation (Cl2 → 2Cl•, UV) → Propagation (Cl• + CH4 → CH3• + HCl; CH3• + Cl2 → CH3Cl + Cl•) → Termination (radicals combine).

Alkenes — Synthesis & Addition Reactions Basic
MAKING ALKENES:
Elimination of alcohol (dehydration):
CH3CH2OH --> CH2=CH2 + H2O (conc. H2SO4 or Al2O3, 170°C)
Elimination of HX from halogenoalkane:
CH3CH2Br + KOH --> CH2=CH2 + KBr + H2O (alcoholic KOH, heat)

REACTIONS OF ALKENES (Electrophilic Addition):
+ HBr (Markovnikov):
CH3CH=CH2 + HBr --> CH3CHBrCH3 (major product, 2° carbocation)
+ H2O (hydration):
CH2=CH2 + H2O --> CH3CH2OH (H3PO4/H2SO4, 300°C, 70 atm)
+ Br2 (halogenation):
CH2=CH2 + Br2 --> CH2BrCH2Br (CCl4 solvent; decolourises brown Br2)
+ H2SO4 then H2O (indirect hydration):
CH2=CH2 + H2SO4 --> CH3CH2OSO3H --> CH3CH2OH + H2SO4
Oxidation with cold dilute KMnO4:
CH2=CH2 + [O] + H2O --> CH2(OH)CH2(OH) (diol; purple KMnO4 decolourises)
Ozonolysis:
R-CH=CH-R' + O3 --> RCHO + R'CHO (then Zn/H2O; cleaves double bond)

Markovnikov's Rule: H adds to the carbon already bearing more H atoms (gives most stable carbocation intermediate).

Alkynes — Synthesis & Reactions Intermediate
Making alkynes — double dehydrohalogenation:
CH2BrCH2Br + 2KOH --> HC≡CH + 2KBr + 2H2O (alcoholic KOH, heat)

Partial hydrogenation (Lindlar's catalyst → cis-alkene):
HC≡CH + H2 --> cis-CH2=CH2 (Pd/CaCO3 + quinoline = Lindlar's)

Full hydrogenation → alkane:
HC≡CH + 2H2 --> CH3CH3 (Ni catalyst, 150°C)

Hydration → ketone (Markovnikov):
CH3C≡CH + H2O --> CH3COCH3 (H2SO4/HgSO4 catalyst)

Terminal alkyne + strong base → acetylide nucleophile:
HC≡CH + NaNH2 --> HC≡C:Na+ + NH3 (then reacts with RX → chain extension)
Alcohols — Synthesis & Reactions Basic
MAKING ALCOHOLS:
Hydration of alkene: CH2=CH2 + H2O --> CH3CH2OH (H3PO4, 300°C)
SN2 substitution of halogenoalkane: CH3Br + NaOH --> CH3OH + NaBr (aq. NaOH)
Fermentation: C6H12O6 --> 2C2H5OH + 2CO2 (zymase enzyme, 25-37°C)
Grignard + carbonyl: RMgBr + RCHO --> R-CH(OH)-R' (then H3O+)
Reduction of aldehyde/ketone/acid: RCHO + 2[H] --> RCH2OH (NaBH4 or LiAlH4)

REACTIONS OF ALCOHOLS:
Dehydration → alkene: CH3CH2OH --> CH2=CH2 + H2O (conc. H2SO4, 170°C)
Oxidation (1° → aldehyde → carboxylic acid):
RCH2OH --> RCHO (K2Cr2O7/H2SO4, distill)
RCHO --> RCOOH (K2Cr2O7/H2SO4, reflux)
Oxidation (2° → ketone): R2CHOH --> R2C=O (K2Cr2O7/H2SO4)
Halogenation → halogenoalkane: CH3CH2OH + HBr --> CH3CH2Br + H2O (or SOCl2/PCl5)
Esterification: CH3COOH + C2H5OH = CH3COOC2H5 + H2O (conc. H2SO4 cat.)
Halogenoalkanes — Nucleophilic Substitution & Elimination Intermediate
MAKING HALOGENOALKANES:
From alcohol + HX: ROH + HBr --> RBr + H2O
From alcohol + PCl5: ROH + PCl5 --> RCl + POCl3 + HCl
From alcohol + SOCl2: ROH + SOCl2 --> RCl + SO2 + HCl
Addition of HX to alkene: CH2=CH2 + HBr --> CH3CH2Br

REACTIONS (Nucleophilic Substitution SN1/SN2):
→ Alcohol (aq NaOH): RBr + NaOH(aq) --> ROH + NaBr
→ Nitrile/CN (chain extension +1C): RBr + KCN --> RCN + KBr (ethanol solvent)
→ Amine: RBr + NH3(excess) --> RNH2 + NH4Br (ethanol, sealed tube)
→ Ether (Williamson synthesis): RBr + RONa --> ROR + NaBr
→ Grignard reagent: RBr + Mg --> RMgBr (dry ether; very versatile nucleophile)
Elimination → alkene (alc KOH): RBr + KOH --> alkene + KBr + H2O (hot, alcoholic)

SN2: 1° halogenoalkanes, one step, inversion of config. | SN1: 3° halogenoalkanes, two steps, racemisation. | Rate of leaving group: I > Br > Cl > F.

Aldehydes & Ketones — Synthesis & Nucleophilic Addition Intermediate
MAKING ALDEHYDES:
Oxidation of 1° alcohol (distill off product): RCH2OH --> RCHO (K2Cr2O7/H+, distil)
Reduction of acyl chloride: RCOCl + H2 --> RCHO (Pd/BaSO4 = Rosenmund reduction)

MAKING KETONES:
Oxidation of 2° alcohol: R2CHOH --> R2C=O (K2Cr2O7/H+, reflux)
Friedel-Crafts acylation: C6H6 + RCOCl --> C6H5COR + HCl (AlCl3, anhydrous)

REACTIONS (Nucleophilic Addition):
+ NaBH4 (reduction → alcohol): RCHO + 2[H] --> RCH2OH
+ LiAlH4 (stronger reduction): RCHO --> RCH2OH (then H3O+; dry ether)
+ HCN (cyanohydrin formation): RCHO + HCN --> RCH(OH)CN (KCN cat.; +1C chain)
+ Grignard (→ alcohol): RCHO + R'MgBr --> RR'CHOH (then H3O+)
Aldol condensation (base): 2CH3CHO --> CH3CH(OH)CH2CHO (dil NaOH, cold)
Carboxylic Acids & Derivatives — Synthesis & Interconversions Intermediate
MAKING CARBOXYLIC ACIDS:
Oxidation of 1° alcohol/aldehyde (reflux): RCH2OH --> RCOOH (K2Cr2O7/H+, reflux)
Hydrolysis of nitrile: RCN + H2O --> RCOOH + NH3 (dil. H2SO4 or NaOH, reflux)
Grignard + CO2: RMgBr + CO2 --> RCOOMgBr --> RCOOH (then H3O+)
Hydrolysis of ester: RCOOR' + NaOH --> RCOONa + R'OH (saponification)

CARBOXYLIC ACID → DERIVATIVES:
→ Acyl chloride (+ PCl5 or SOCl2): RCOOH + PCl5 --> RCOCl + POCl3 + HCl
→ Ester (+ alcohol, H2SO4 cat.): RCOOH + R'OH = RCOOR' + H2O
→ Amide (+ amine or NH3, heat): RCOOH + NH3 --> RCONH2 + H2O
→ Acid anhydride (+ P2O5): 2RCOOH --> (RCO)2O + H2O
Reduction → aldehyde (then alcohol): RCOOH + LiAlH4 --> RCH2OH (dry ether, then H3O+)
Acyl Chlorides — Reactions (Very Reactive Electrophiles) Intermediate
Acyl chloride (RCOCl) reacts rapidly with nucleophiles:
+ H2O → carboxylic acid: RCOCl + H2O --> RCOOH + HCl
+ ROH → ester: RCOCl + R'OH --> RCOOR' + HCl (no acid catalyst needed; fast, irreversible)
+ NH3 → amide: RCOCl + 2NH3 --> RCONH2 + NH4Cl
+ amine → N-substituted amide: RCOCl + R'NH2 --> RCONHR' + HCl
Friedel-Crafts acylation → aromatic ketone: C6H6 + RCOCl --> C6H5COR + HCl (AlCl3)

Acyl chlorides are more reactive than carboxylic acids — no catalyst needed and reactions are irreversible. Used to make esters in high yield.

Esters — Synthesis & Hydrolysis Basic
MAKING ESTERS:
Esterification (reversible): RCOOH + R'OH = RCOOR' + H2O (conc. H2SO4 cat., reflux)
From acyl chloride (irreversible, fast): RCOCl + R'OH --> RCOOR' + HCl
From acid anhydride: (RCO)2O + R'OH --> RCOOR' + RCOOH

HYDROLYSIS OF ESTERS:
Acid hydrolysis (reversible): RCOOR' + H2O = RCOOH + R'OH (H2SO4, reflux)
Base hydrolysis/saponification (irreversible): RCOOR' + NaOH --> RCOONa + R'OH (reflux)
Amines — Synthesis & Reactions Intermediate
MAKING AMINES:
SN2 from halogenoalkane + excess NH3: RBr + 2NH3 --> RNH2 + NH4Br (ethanol, sealed tube)
Reduction of nitrile: RCN + 4[H] --> RCH2NH2 (LiAlH4, dry ether; or H2/Ni)
Reduction of nitro group (aromatic amines): C6H5NO2 + 6[H] --> C6H5NH2 + 2H2O (Sn/HCl, then NaOH)
Hofmann degradation (amide → 1° amine, -1C): RCONH2 + Br2 + 4NaOH --> RNH2 + Na2CO3 + 2NaBr + 2H2O

REACTIONS OF AMINES:
As base + HCl: RNH2 + HCl --> RNH3+Cl- (salt formation)
Acylation with acyl chloride → amide: RNH2 + R'COCl --> R'CONHR + HCl
Diazotisation (aromatic, 0–5°C): C6H5NH2 + NaNO2 + HCl --> C6H5N2+Cl- + NaCl + 2H2O
Coupling reaction (azo dye): C6H5N2+ + C6H5OH --> C6H5-N=N-C6H4OH (orange azo dye)
Amides — Synthesis & Reactions Intermediate
MAKING AMIDES:
From acyl chloride + amine/NH3: RCOCl + 2NH3 --> RCONH2 + NH4Cl
From carboxylic acid + NH3 (heat ammonium salt): RCOONH4 --> RCONH2 + H2O

REACTIONS OF AMIDES:
Acid hydrolysis → carboxylic acid + ammonium salt:
RCONH2 + H2O + H+ --> RCOOH + NH4+ (reflux with dil. H2SO4)
Base hydrolysis → carboxylate + ammonia:
RCONH2 + NaOH --> RCOONa + NH3 (reflux)
Reduction → amine (+ 1 carbon retained):
RCONH2 + 4[H] --> RCH2NH2 (LiAlH4, dry ether)
Nitriles — Synthesis & Reactions (Chain Extension) Intermediate
MAKING NITRILES (+1 carbon added):
RBr + KCN --> RCN + KBr (ethanol solvent; SN2 on 1° halogenoalkane)

REACTIONS:
Hydrolysis → carboxylic acid: RCN + H2O --> RCOOH + NH3 (dil. H2SO4, reflux)
Reduction → primary amine: RCN + 4[H] --> RCH2NH2 (LiAlH4 or H2/Ni)
Addition to carbonyl → cyanohydrin: RCHO + HCN --> RCH(OH)CN (KCN cat.)

Nitrile formation via KCN is crucial for chain extension (adds 1 carbon to skeleton). Restricted to 1° halogenoalkanes to avoid elimination.

Grignard Reagents — Versatile Carbon Nucleophile Advanced
Formation: RBr + Mg --> RMgBr (dry ether; strictly anhydrous conditions)

Grignard + carbonyl compounds (then H3O+):
+ HCHO → primary alcohol: RMgBr + HCHO --> RCH2OH (1 extra C)
+ RCHO → secondary alcohol: RMgBr + R'CHO --> R-CH(OH)-R'
+ R2CO → tertiary alcohol: RMgBr + R'COR'' --> R-C(OH)(R')(R'')
+ CO2 → carboxylic acid: RMgBr + CO2 --> RCOOH (then H3O+)
+ ester → tertiary alcohol (2 equivalents): 2RMgBr + R'COOR'' --> R2R'COH
+ H2O → alkane (destroys Grignard): RMgBr + H2O --> RH + Mg(OH)Br

Grignard reagents are powerful carbanion equivalents. Must be prepared in absolutely dry conditions — water destroys the reagent. Always add dilute acid (H3O+) to hydrolyse the magnesium alkoxide intermediate.

Benzene & Aromatic Chemistry — Electrophilic Aromatic Substitution (EAS) Advanced
1. Nitration:
C6H6 + HNO3 --> C6H5NO2 + H2O (conc. H2SO4, 55°C; NO2+ electrophile)

2. Halogenation (requires Lewis acid):
C6H6 + Cl2 --> C6H5Cl + HCl (AlCl3 or FeCl3 cat.; no UV)
C6H6 + Br2 --> C6H5Br + HBr (FeBr3 cat.)

3. Friedel-Crafts Alkylation:
C6H6 + RCl --> C6H5R + HCl (anhydrous AlCl3; gives polyalkylation problem)

4. Friedel-Crafts Acylation (preferred):
C6H6 + RCOCl --> C6H5COR + HCl (anhydrous AlCl3; no overreaction)

5. Sulfonation:
C6H6 + H2SO4 --> C6H5SO3H + H2O (fuming H2SO4 or oleum, 80°C)

Reduction of nitrobenzene → aniline:
C6H5NO2 + 6[H] --> C6H5NH2 + 2H2O (Sn/conc. HCl, then NaOH)

Activating groups (ortho/para directors): -OH, -NH2, -OCH3, -R
Deactivating groups (meta directors): -NO2, -COOH, -CHO, -COR, -SO3H, -CN
Polymerisation — Addition & Condensation Basic
Addition polymerisation (no atoms lost):
n(CH2=CH2) --> -[CH2-CH2]n- (poly(ethene))
n(CH2=CHCN) --> -[CH2-CHCN]n- (PAN/acrylic)
n(CF2=CF2) --> -[CF2-CF2]n- (PTFE/Teflon)
n(CH2=CHCl) --> -[CH2-CHCl]n- (PVC)

Condensation polymerisation (small molecule lost, e.g. H2O or HCl):
Polyester (Terylene/PET):
n HOCH2CH2OH + n HOOC-C6H4-COOH --> -[OCH2CH2OOC-C6H4-CO]n- + nH2O
Polyamide (Nylon-6,6):
n H2N(CH2)6NH2 + n HOOC(CH2)4COOH --> -[NH(CH2)6NHCO(CH2)4CO]n- + nH2O
Polypeptide/protein:
n H2N-CHR-COOH --> -[NH-CHR-CO]n- + nH2O (peptide bonds)
